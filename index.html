01
CVSS 10.0 · CERT-IN

Critical IDOR in Production API

Disclosure Reported via CERT-In
Class OWASP API1 · IDOR
Severity Critical (CVSS v3.1: 10.0)

Uncovered an unauthenticated/cross-tenant Insecure Direct Object Reference in a live production REST API exposing sensitive PII and account records across the user base; coordinated remediation through CERT-In.

Attack Vector

Predictable object identifiers in REST endpoints lacked server-side ownership binding against the authenticated JWT subject claim.

Forensic Impact

Full horizontal account enumeration and unauthorized retrieval of sensitive PII and transaction metadata across arbitrary tenant accounts.

Remediation & Case Study

Enforced resource-level policy checks bound to session context and migrated sequential IDs to cryptographically random UUIDv4 tokens. Read full writeup ↗

02
CRYPTOGRAPHIC FLAW

Hardcoded AES-128-GCM Keys

Target Android Mobile App
Class OWASP M10 · Cryptography
Severity High · Full Payload Decryption

Reverse-engineered compiled DEX bytecode and native libraries to recover static AES-128-GCM symmetric keys, enabling offline decryption of intercepted API traffic.

Attack Vector

Decompiled APK via JADX & Apktool, locating static byte arrays passed directly into SecretKeySpec and GCMParameterSpec initializers.

Forensic Impact

Complete compromise of transport-layer payload confidentiality, allowing any attacker or MITM proxy to decrypt and forge encrypted client requests.

Remediation Architecture

Replaced static client keys with ephemeral session keys negotiated per-device and backed by Android Hardware Keystore attestation.

03
ACCESS CONTROL

Broken Object Level Auth (BOLA)

Target Multi-Tenant Web API
Class OWASP API1 · BOLA
Severity High · Cross-Account Mutation

Identified missing object-level authorization checks on state-changing PUT/DELETE endpoints, allowing low-privilege users to modify records belonging to other tenants.

Attack Vector

Parameter tampering of nested organization and profile IDs inside JSON request bodies during authenticated session replay in Burp Suite.

Forensic Impact

Unauthorized modification of account settings and deletion of tenant records across organizational boundaries.

Remediation Architecture

Implemented centralized middleware ownership guards verifying tenant/user lineage on every ORM query prior to mutation.

04
MOBILE STORAGE

Cleartext Local Data Storage

Target Android Sandbox
Class OWASP M9 · Data Storage
Severity Medium-High · Token Theft

Discovered unencrypted bearer tokens, session cookies, and user PII persisted inside world-accessible SQLite databases and SharedPreferences XML files.

Attack Vector

ADB backup extraction and sandbox file inspection under /data/data/<package>/shared_prefs/ and databases/.

Forensic Impact

Persistent account takeover via stolen long-lived refresh tokens without requiring user credentials or MFA re-verification.

Remediation Architecture

Migrated sensitive persistence to EncryptedSharedPreferences and SQLCipher with keys sealed inside the Android Keystore TEE.

05
PRIVILEGE ESCALATION

Vertical Privilege Escalation

Target RBAC Admin Portal
Class OWASP API5 · Function Auth
Severity High · Admin Takeover

Bypassed frontend role gates and invoked administrative API routes directly using a standard user JWT, achieving full administrative control.

Attack Vector

JavaScript bundle recon revealed undocumented /api/v1/admin/* routes that validated authentication state but omitted role-claim enforcement.

Forensic Impact

Unprivileged users could elevate role assignments, export global user directories, and alter system configurations.

Remediation Architecture

Implemented strict deny-by-default RBAC decorators on all administrative controllers with immutable audit logging.
