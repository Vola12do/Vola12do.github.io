Vulnerability Discoveries

↵ click any ticket to expand PoC notes
#01

Critical IDOR in Production REST API

CVSS 10.0 · Disclosed via CERT-In

Uncovered an unauthenticated/cross-tenant Insecure Direct Object Reference exposing sensitive PII and user records across the platform; coordinated remediation via CERT-In.

Vector & Root Cause Sequential object identifiers in REST endpoints lacked server-side ownership validation against the authenticated JWT subject claim.
Fix & Writeup Enforced strict tenant-bound authorization middleware and UUIDv4 identifiers. Read writeup ↗
#02

Hardcoded AES-128-GCM Cryptographic Keys

High · Android APK Reverse Engineering

Extracted static symmetric AES-128-GCM keys embedded inside compiled DEX bytecode, enabling full offline decryption of intercepted mobile API payloads.

Vector & Root Cause Decompiled APK with JADX/Apktool and traced hardcoded byte arrays passed directly into SecretKeySpec and GCMParameterSpec.
Remediation Replaced static keys with per-session ephemeral keys backed by Android Hardware Keystore attestation.
#03

Broken Object Level Authorization (BOLA)

High · Multi-Tenant Web API

Bypassed object-level access controls on state-changing PUT/DELETE API routes, allowing cross-account data manipulation.

Vector & Root Cause Tampered nested profile/organization IDs inside JSON request bodies during authenticated session replay in Burp Suite.
Remediation Added centralized ORM scoping guards verifying tenant ownership before executing mutations.
#04

Insecure Cleartext Local Data Storage

Medium-High · OWASP Mobile M9

Recovered unencrypted bearer tokens, session cookies, and user PII stored inside local Android SQLite databases and SharedPreferences XML files.

Vector & Root Cause Extracted sandbox storage under /data/data/<pkg>/shared_prefs/ via ADB backup & device forensics.
Remediation Migrated persistence to EncryptedSharedPreferences and SQLCipher sealed by Android Keystore.
#05

Vertical Privilege Escalation (Admin Takeover)

High · OWASP API5 Function Auth

Invoked privileged administrative API endpoints using a low-privilege user JWT by bypassing client-side role checks.

Vector & Root Cause Discovered privileged /api/v1/admin/* routes in JS bundles that checked authentication state but omitted server-side role verification.
Remediation Implemented deny-by-default RBAC controller guards and immutable admin audit logs.
